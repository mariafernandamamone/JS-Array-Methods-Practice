# JS Array Methods Practice 🚀

Colección de 45 ejercicios prácticos de JavaScript (ES6+) enfocados en programación funcional, manipulación de arreglos de objetos y transformaciones de datos en entorno Node.js.

## 📁 Estructura del Proyecto

```
.
├── package.json
├── data/
│   ├── empleados.js
│   ├── artistas.js
│   └── estudiantes.js
├── 01-empleados/   
├── 02-artistas/    
└── 03-estudiantes/ 
```

## 🛠️ Conceptos y Métodos Aplicados
Métodos iterativos de Arrays: .reduce(), .map(), .filter(), .forEach(), .some(), .every(), .find().

Estructuras Complejas y Anidadas: Procesamiento de arreglos dentro de objetos con relaciones múltiples.

Frecuencias y Agregaciones: Algoritmos para conteo de ocurrencias, búsqueda de máximos, promedios y resolución de empates con Object.keys() y Object.values().

Módulos ES6: Importación y exportación de datasets mediante sintaxis de módulos (import / export).

## ⚙️ Ejecución

Para ejecutar cualquier ejercicio en la consola con Node.js, tomate de referencia la estructura `<carpeta>/<archivo>.js`:

```bash
# Ejemplo: Ejercicio de estudiantes
node 03-estudiantes/13-familiarPreferido.js

# Ejemplo: Ejercicio de empleados
node 01-empleados/05-empleadosConMasLenguajes.js
```
